# LarkusAC — Minecraft Anticheat

LarkusAC is a custom Minecraft anticheat project developed using Skript.

## Features

- **Movement detection:** Checks for suspicious speed and flight behaviour.
- **NoFall checks:** Detects suspicious fall-related behaviour.
- **Jesus checks:** Includes checks for unusual movement across liquids.
- **Packet checks:** Includes checks for suspicious packet behaviour.
- **Staff alerts:** Provides alerts to help staff review suspicious activity.
- **Logging:** Supports recording detections for review.
- **Configurable punishments:** Includes configurable kick and autoban options.

## Development

This project demonstrates my experience developing Skript-based server systems, handling player events, implementing detection logic, and building staff-facing tools.

## Testing and limitations

Anticheat checks require testing and appropriate configuration. Detection accuracy and performance can vary depending on the server environment, so the system should be thoroughly tested before being relied on for automated punishments.
