# Node — Minecraft Server Development

Node was a Minecraft server I owned and developed from the ground up using Skript.

## Project Overview

The server featured three gamemodes and a custom lobby. I developed its server systems, gameplay mechanics, commands, and other features.

## Development Work

- Custom Skript-based gameplay systems
- Gamemode features and mechanics
- Custom commands and player interactions
- Lobby-related functionality
- Server troubleshooting and maintenance

## Source Code

This folder contains original Skript files from the Node project. Each script can be reviewed to see examples of my development approach and implementation.

Additional scripts will be organised by gamemode or feature where appropriate.
